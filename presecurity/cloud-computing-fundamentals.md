## What I did
Completed the Cloud Computing Fundamentals room on TryHackMe.

## What I learned
Learned the core cloud concepts: Public, Private, and Hybrid cloud models; the
service types IaaS, PaaS, and SaaS; and AWS's EC2 as an example of on-demand
cloud computers. Also covered key cloud benefits - scalability, pay-as-you-go
pricing, high availability, and global access - and how to manage AWS-style
resources based on cost and efficiency needs.

## What clicked
Understood the difference between renting raw infrastructure (IaaS) versus a
ready-made environment (PaaS) versus finished software (SaaS) - it's a spectrum
of how much you manage yourself versus how much the provider handles for you.

## Why this matters for security
Public vs Private vs Hybrid cloud choices directly affect an organization's
security posture - private clouds offer more control but cost more, while
public clouds are shared and need careful configuration to avoid exposing data.
Many real-world breaches happen from misconfigured cloud storage (like an
exposed AWS S3 bucket), so understanding these models is directly relevant to
spotting and preventing cloud-based security incidents later in SOC work.

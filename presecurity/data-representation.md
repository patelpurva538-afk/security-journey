## What I did
Completed the Data Representation room on TryHackMe.

## What I learned
Learned how computers represent data using different number systems -
decimal, binary, and hexadecimal - and how these are used in practical things
like representing colors (e.g. hex color codes).

## What clicked
Understood that hexadecimal isn't just an abstract math concept - it's used
everywhere in real systems, like color codes, and is a more compact way to
represent binary data than writing out long strings of 1s and 0s.

## Why this matters for security
Hexadecimal shows up constantly in security work - memory addresses, malware
analysis, network packet data, and file signatures are often represented in
hex. Being comfortable converting between binary, decimal, and hex is a small
but foundational skill for later forensics and malware analysis tasks.

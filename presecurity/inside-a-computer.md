## What I did
Completed the Inside a Computer System room on TryHackMe.

## What I learned
Learned about the main hardware components: RAM, CPU, PSU, graphics card,
HDD/SSD, I/O devices, and network adapter - and how each one connects and works
together to make a computer function.

## What clicked
Already had a general sense of how a computer works, but this room reinforced
exactly how each component connects to the others as a system, not just
isolated parts.

## Why this matters for security
Understanding hardware matters for defenders because things like RAM (memory)
are where malware analysis happens (checking what's running in live memory
during an incident), and storage (HDD/SSD) is where forensic investigators look
for evidence after a breach. You can't investigate what you don't understand.

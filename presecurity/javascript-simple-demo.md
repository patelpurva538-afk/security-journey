## What I did
Completed the JavaScript: Simple Demo room on TryHackMe.

## What I learned
Wrote and ran a small JavaScript script using variables, if/else conditionals,
and while loops.

## What clicked
Noticed the exact same core logic from Python (variables, conditionals, loops)
carries over directly - only the syntax changes between languages, not the
underlying way of thinking through a problem.

## Why this matters
JavaScript runs in browsers and is relevant to understanding web-based attacks
(like malicious scripts injected into a webpage). Recognizing that core
programming logic transfers across languages also builds confidence - the
Python skills being built aren't tied to one language, they're a way of
thinking that applies broadly.

## What I did
Completed the Linux CLI Basics room on TryHackMe.

## What I learned
Practiced navigating the Linux filesystem, searching for files, inspecting
system information, reading important configuration files, and using various
commands to follow clues and complete missions inside a Linux environment.

## What clicked
Got comfortable moving around a Linux system using only the command line
instead of a GUI - searching for specific files and reading config files
started to feel natural rather than intimidating.

## Why this matters for security
Nearly all blue team investigation work happens on Linux servers via the
command line - reading log files, searching for specific patterns across the
filesystem, and inspecting configuration files for signs of tampering are
exact tasks a SOC analyst does during an investigation. This room is the
direct foundation for the log-analysis and SIEM triage skills coming up in
SOC Level 1.

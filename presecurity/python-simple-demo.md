## What I did
Completed the Python: Simple Demo room on TryHackMe - my first hands-on
scripting exercise.

## What I learned
Wrote and ran a Python script using while loops, if/elif/else conditional
logic, and the random.randint() function to generate random numbers.

## What clicked
Got to actually see these concepts work together in a real running script
instead of just reading about them - a while loop kept the program running,
and if/elif/else branched the logic based on the random number generated.

## Why this matters
This is the same logic pattern used in real security scripts - e.g. a script
that loops through log entries (while/for loop) and branches its behavior
based on conditions (if/elif/else), like flagging a line only if it matches
certain criteria. Small demo, but the underlying pattern scales directly to
the log-parsing scripts planned later.

## What I did
Completed the Windows CLI Basics room on TryHackMe.

## What I learned
Practiced navigating Windows files and folders via command line instead of
clicking through the GUI, locating files without knowing their exact location,
revealing hidden files and directories, reading file contents directly from
the terminal, and gathering basic system and network information.

## What clicked
Noticed the same core ideas from Linux CLI Basics apply here too - navigating,
searching, and reading files from the command line - just with different
command syntax for Windows (Command Prompt/PowerShell) versus Linux (bash).
The underlying skill transfers even though the exact commands differ.

## Why this matters for security
Many organizations run Windows servers and endpoints, so being able to
investigate a Windows machine via CLI - finding hidden files, reading configs,
pulling network info - is just as essential as the Linux skills for a SOC
analyst who won't always know in advance which OS an incident involves.

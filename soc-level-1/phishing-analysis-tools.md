## What I did
Completed the Phishing Analysis Tools room on TryHackMe.

## What I learned
Learned about specific tools used for phishing analysis - URL scanners,
sandbox tools (for safely detonating suspicious attachments/links), and
header analyzers - and how real-world phishing cases get solved using these
tools, including what information gets collected during an investigation.

## What clicked
Understood these tools automate and verify what the manual checklist from
Phishing Analysis Fundamentals covers - rather than manually guessing if a
link is malicious, a URL scanner or sandbox gives a definitive, safe answer
without risking actually clicking or opening something dangerous yourself.

## Why this matters
Using dedicated tools instead of manual inspection alone is both faster and
safer - a sandbox specifically prevents an analyst from accidentally
executing malware while investigating it. This is the practical, tool-based
version of everything built up through the Phishing Analysis module so far.

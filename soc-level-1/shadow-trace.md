## What I did
Completed the Shadow Trace room on TryHackMe - a capstone-style scenario
combining malware analysis and LOTL detection.

## What I learned
Applied malware analysis techniques together with Living Off The Land
detection in one combined investigation scenario, rather than practicing
each skill in isolation.

## What clicked
Combining these two skills in one case showed how a real investigation
rarely stays in one category - a case might start by suspecting a LOTL
technique, then require actual malware analysis (hashing, checking for
known signatures) once a suspicious file is found, moving fluidly between
both skill sets.

## Why this matters
This is a strong capstone for the Malware Concepts module - showing the
ability to combine classification, static/dynamic analysis, and LOTL
detection into one coherent investigation is exactly the kind of applied
skill that distinguishes a real analyst from someone who only knows
isolated concepts.

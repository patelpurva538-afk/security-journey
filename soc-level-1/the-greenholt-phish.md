## What I did
Completed The Greenholt Phish room on TryHackMe - an end-to-end investigation
scenario combining everything from the Phishing Analysis module.

## What I learned
Applied the full phishing analysis process together in one scenario -
checking SPF records to verify sender authenticity and using sha256sum to
generate file hashes for identifying and checking attachments against known
malicious file signatures.

## What clicked
This tied the whole Phishing Analysis module together into one real
investigation - sender/header checks, tool-based verification (SPF), and
hash-based file identification (sha256sum) all combined into a single case,
rather than practiced as separate isolated skills.

## Why this matters
This is the closest simulation yet to an actual real-world phishing
investigation a Tier 1 analyst would handle - pulling together detection,
verification, and evidence gathering (hashes) into one coherent case, which
is exactly the kind of scenario a portfolio should demonstrate to show
real applied skill, not just individual concepts.
